# Ship Shit Dev - Workspace Bundle

Project setup and workspace initialization

## Installation

```bash
/plugin marketplace add shipshitdev/skills
/plugin install shipshitdev-workspace@shipshitdev
```

## Included Skills

- `project-init-orchestrator`
- `env-setup`
- `linter-formatter-init`
- `stack-validator`
- `content-script-developer`
- `package-architect`
- `artifacts-builder`
- `wizard`
- `open-source-checker`
- `devcontainer-setup`
